# 1. ¿Qué duele hoy?
# * Invisibilidad y reacción tardía: No se conocen las variables ambientales en tiempo real ni hay alertas automáticas ante fallas.
# * Falta de históricos: Imposibilidad de analizar tendencias de confort o consumo energético.
# * Riesgo de saturación: Una base de datos común se ralentizará rápidamente al recibir más de 115,000 lecturas diarias de forma continua.
# 2. ¿Quién sufre ese dolor?
# * Personal de mantenimiento: Trabaja a ciegas y depende de inspecciones manuales.
# * Administración: Carece de datos para decidir sobre infraestructura y climatización.
# * Público general: Soporta espacios con mala ventilación o temperaturas incómodas.
# 3. ¿Qué pasa si el sistema se cae una hora?
# * Brecha de datos: Se pierden unas 4,800 lecturas, dejando un punto ciego en el tablero.
# * Riesgo operativo bajo pero crítico: No se detiene la universidad ni se pierde dinero, pero las alertas no se dispararán si ocurre una anomalía en esa hora.
